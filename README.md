# HPC Causal Model Analysis

Research codebase for root cause analysis of the Frontier supercomputer (OLCF) using 18.3 billion system log events. The project combines transformer-based sequence modeling with causal discovery using transfer entropy and pcmci+ methods to identify failure propagation patterns, and exposes the results through an AI  agent for evaluation.

All code is under the `codes/` directory. See `codes/README.md` for a full description of the pipelines.
